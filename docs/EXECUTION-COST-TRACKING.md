# SunPowerOS — Execution Cost Tracking
## Site Expenditure, Labor, Rental & Budget Reconciliation

---

## 1. Overview

Execution Cost Tracking (`CST-YYYY-000001`) provides detailed financial accounting of on-site expenses incurred during solar project installation.

## 2. Cost Categories

| Category | Typical Incurred Expenses |
|---|---|
| `LABOR` | Daily wages, subcontractor installation charges, electrician fees |
| `EQUIPMENT_RENTAL` | Scaffolding rental, scissor lifts, crane hoisting, megger/earth tester equipment |
| `TRAVEL_LODGING` | Crew transport, vehicle fuel, site accommodation and daily allowances |
| `PERMITS_FEES` | DISCOM application fees, CEIG electrical inspector fees, meter testing charges |
| `CONSUMABLES` | Cable ties, conduit clips, ferrule sleeves, anchor bolts, civil cement/sand |
| `MISCELLANEOUS` | Site water/electricity charges, temporary storage bay rental, debris removal |

## 3. Reporting & Analytics
- Multi-currency support (Default INR `₹`).
- Category-wise expenditure breakdown against Phase 2 BOM Cost Estimates.
- Real-time project margin tracking and variance alerts for cost overruns.
