# SunPowerOS — Mobile Field Technician Portal
## Touch-Optimized Rooftop Field Execution Interface

---

## 1. Overview

The Mobile Technician Portal (`/technician`) is a responsive web application designed for on-site field technicians working in bright sunlight on 360px-480px touchscreens.

## 2. Key Mobile Capabilities

- **Touch-Friendly Interface:** High contrast, large touch targets (min 44px), thumb-accessible navigation bar.
- **My Tasks Tab:**
  - View assigned installation work orders and standard 9 tasks.
  - One-tap status updates (`NOT_STARTED` -> `IN_PROGRESS` -> `COMPLETED`).
  - Real-time task progress bar.
- **Daily Safety Tab:**
  - Pre-work toolbox talk confirmation.
  - PPE compliance checklist and rooftop fall protection confirmation.
  - One-tap submission of daily safety review.
- **Serial Scanner Tab:**
  - Fast barcode/QR scanning of solar PV modules and inverters.
  - Match serial numbers against expected delivery challans.
  - Flag damaged modules or packaging tears directly from the roof.
- **Commissioning Tests Tab:**
  - Record Voc, Isc, megger insulation resistance, and earth pit resistance directly on site.
  - Immediate pass/fail feedback against statutory thresholds.
